An offline web guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies, with a cited guide in plain words for every trophy, a six-stage roadmap to the platinum, a missable flag on the one trophy that can be missed, and a spoiler-safe checklist that saves in your browser.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
